G3 Hybrid Test and Evaluation
=============================

The tools in this repository are intenteded to be used to work with and evaluate
ST's G3 Hybrid evaluation boards. It allows us a much better programatic way to
work with the boards than trying to use ST's Windows application. We can use a
CLI to interact with the boards, as well as the ablity to R&D how we want to
utlize the technology.

Tools
-----

### g3_cli

`g3_cli` is a CLI tool to run various commands to the ST8500 SOC firmware that
runs the PLC-Hybrid solution.
